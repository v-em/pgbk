# План развития

Проект [спецификации отдельного UI v1](ui-v1.md) описывает просмотр каталога S3, порядок восстановления, расписания, ручной запуск и мониторинг Job.

Дополнительная консоль реализована отдельными image и chart; см. [установку UI и локальные проверки](ui-operations.md). Поток логов, отмена, скачивание архивов, запуск restore/verify и редактирование профилей/расписаний остаются за рамками v1.

Инкрементальные physical backup и PITR остаются отдельным будущим этапом: версионированные метаданные цепочек/WAL, retention с учётом зависимостей и автономная проверка восстановления. Настройки 0.2 не обещают эти возможности.
